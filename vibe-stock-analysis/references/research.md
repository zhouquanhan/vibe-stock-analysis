# 研究与计算口径

## 按问题选择证据

- **行情与技术面**。报价先报告交易地时间、交易所、币种、时效分类和涨跌。趋势以完成的 K 线为单位，明确日线或周线。图形信号结合成交量、跳空和相对强弱解释。滚动极值可作观察位，盘中突破等到对应 bar 完成后再做确认。
- **财报与估值**。区分财季截止日、实际披露日、报价日和估值倍数的分母期。先找监管文件、发行人业绩公告、电话会或量化指引。核对异常收益、重述、汇率、存托比例、回购及股类。挑选业务或利润结构可比的公司，说明差异。高增长估值应结合可持续盈利、现金转化和增长弹性。周期性、亏损、银行或重资产股票需选择适合其商业模式的指标。
- **新闻、行业和宏观**。标题只作为线索。把事件时间和刊发时间分开，回查公告原文和相关监管部门。讨论利率、通胀、资本支出、供应链、需求、替代产品和监管时，写清传导渠道。分析师目标和前瞻 EPS 属于外部预期。若缺少可靠分布或修订历史，给出定性结论。
- **综合研判**。回答用户的资产、期限和问题。先给带条件的判断，再给最重要的依据与反证。可用乐观、基准、悲观三种情况，逐一写明触发因素、需要观察的数据和证伪条件。若需要估值区间，公开盈利和倍数假设，不为情景指定无依据的概率。用发行人和监管来源、日期与可计算的数据说清判断依赖的事实。

## 程序计算

| 结果 | 口径 |
| --- | --- |
| MA 和 EMA | MA 为窗口算术平均。EMA 由首个收盘值开始递推，权重为 `2/(n+1)`，达到窗口后才报告。 |
| MACD、RSI、布林带 | MACD 用 EMA 12/26/9，柱为线减信号线。RSI14 使用 Wilder 均值初始化及递推，平盘为 50。布林带为 20 期均值加减两个样本标准差，沿用上游技术工具口径。 |
| KDJ、ATR、量价 | KDJ 9/3/3 起始 K、D 为 50，ATR14 用真实波幅和 Wilder 平滑。量比用最新值除以包含该 bar 的 20 根有效成交量均值。支撑压力为近 20 根高低极值，突破对照前 20 根。 |
| 日线表现与风险 | 30/90/180/365 日收益锚定目标日期及之前七日内最后一个收盘。样本收益、对数收益样本标准差年化与最大回撤使用同一完成序列。日、周、月年化惯例为 252、52、12。基准对齐两个序列共同日期，使用本币，指数与 ETF 或含分红股票可能是不同收益口径。 |
| 估值与同业 | PE/PB/PS 分别使用近四个连续财季盈利、最近账面权益、近四季营收。在币种匹配且分母为正时计算。SEC 历史估值采样使用申报后第一个可核验收盘、最近披露的普通股股数和首次披露口径。PEG 只在提供商有可解释的预期口径时使用。 |
| 回测 | 均线多头或现金。当天完成的收盘生成信号，下一个有数据的交易日开盘成交。成本每边施加，允许分数股，最后尚持有的仓位收盘市值计价。同日、同成本买入持有用于比较。交易次数和胜率只用已闭合往返交易。 |

复权、交易日缺口、市场停牌或行情源切换都可改变计算。策略样本回测不包含流动性、头寸容量、现金利息、税费结构和真实成交模拟。调整过参数时说明是否利用了整个样本。报告最低应给出区间、成本、基准、回撤和结果为何可能无法外推。
